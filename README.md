# nullevi03-model

nullevi03の3Dモデル、アニメーション、プレビューの公開リポジトリです。

現在、配布用アセットを準備しています。配布ファイルとプレビューが揃い次第、このREADMEに掲載します。

## モデルについて

三面図v01を参考に再構築したモデルです。Blender版は38ボーンのリグを備え、手振りとお辞儀の8秒アニメーションを含みます。3段階のトゥーンシェーディングと動的な輪郭線は、Blenderのネイティブ表現です。

GLB版はPBRマテリアルによる近似表現です。Blenderのトゥーン表現と同じ見た目を保証するものではなく、輪郭線は含みません。表示は使用するビューアーや照明によって変わります。
